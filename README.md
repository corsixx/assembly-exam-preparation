# Computer Architecture & Java Exam Preparation 🎓

This repository contains my coding exercises for the **Computer Architecture** exams. It is organized into different lessons.
## 🔬 Computer Architecture (Assembly LC-2)
In this section, I focus on the fundamentals of computer organization using the **LC-2 (Little Computer 2)** Instruction Set Architecture. 

Key topics covered in my LC-2 programs:
* **Arithmetic Operations:** Implementation of basic math using registers.
* **Control Flow:** Using conditional branches and loops to manage program logic.
* **Memory Access:** Understanding how to load and store data.
* **I/O Handling:** Managing basic input and output operations.

## 📂 Project Structure
* `/assembly`: LC-2 Assembly source code (`.asm`) and related files.
* `.gitignore`: Configured to exclude compiled files (`.class`, `.bin`, `.obj`).

## 🛠️ Tools Used
* **LC-2 Simulator[LC2edit/LC2simulate(windows)]:** For testing and debugging Assembly code.
